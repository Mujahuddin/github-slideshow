## LEARNING OBJECTIVES

By the end of this book you will be able to:

- Explain what JDK, JRE, and JVM are, how classes are loaded, and how memory
  (Heap/Stack/Metaspace) and Garbage Collection actually work — not just definitions.
- Apply OOP and SOLID principles to real code, and explain trade-offs when a
  principle is deliberately broken.
- Use Collections correctly, including explaining `HashMap` internals,
  `equals`/`hashCode` contracts, and when to pick which collection.
- Write idiomatic Java 8+ code with Streams, Lambdas, Optional, and Method
  References — and know when NOT to use them.
- Use Java 11/17 features (var, Records, Sealed Classes, text blocks) appropriately.
- Reason about concurrency: threads, synchronization, locks, volatile, atomics,
  `ExecutorService`, `CompletableFuture` — and debug real concurrency bugs.
- Answer Basic → Architect-level interview questions on every topic above, in
  both Telugu-thinking and professional English.

## PREREQUISITES

None — this book starts from zero. Basic comfort with any programming language
helps but is not required.
