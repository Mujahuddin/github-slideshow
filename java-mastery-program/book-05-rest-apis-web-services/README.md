## LEARNING OBJECTIVES

By the end of this book you will be able to:

- Use HTTP methods and status codes with precise, defensible semantics —
  not just "GET reads, POST writes."
- Design versioning, pagination, filtering, and sorting strategies that
  survive years of API evolution.
- Explain JWT structure and verification precisely enough to spot a
  broken or insecure implementation.
- Choose the correct OAuth2 grant type for a given client type, and
  explain why the others are wrong for it.
- Treat OpenAPI specs as a real contract, not after-the-fact documentation.
- Explain what an API Gateway actually does (and doesn't do) and design
  rate limiting that matches real traffic patterns.
- Ship a breaking-looking API change without breaking existing consumers.

## PREREQUISITES

Book 4 (Spring Boot) — this book assumes REST controllers, validation,
exception handling, and Spring Security basics (authentication vs
authorization, `SecurityFilterChain`) are already solid, and goes deeper
specifically into API design and the JWT/OAuth2 flows Book 4 deferred.
