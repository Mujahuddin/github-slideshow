## LEARNING OBJECTIVES

By the end of this book you will be able to:

- Explain *how* Spring Boot auto-configuration actually decides what beans
  to create — not just that "it auto-configures things."
- Externalize configuration correctly (`@ConfigurationProperties` vs
  `@Value`), understand property source precedence, and use profiles
  idiomatically in a Boot application.
- Build REST controllers with proper DTOs, validation, and a consistent,
  centralized exception-handling strategy.
- Explain `@Transactional` propagation and isolation precisely enough to
  debug a real production transaction bug.
- Configure baseline Spring Security (authentication vs authorization) and
  know what's still missing before Book 15's full OAuth2/JWT/DevSecOps treatment.
- Use Actuator and structured logging to make a service observable in production.
- Write the right kind of test (unit / slice / full) for the right layer,
  using Spring Boot's testing annotations correctly.

## PREREQUISITES

Book 3 (Spring Framework) — this book assumes IoC/DI/AOP/bean lifecycle
are already solid, and builds Spring Boot's opinionated layer directly on
top of that foundation.

## SCOPE NOTE

This book covers Spring Data and Spring Security at the *Spring Boot
integration* level — enough to build and defend real endpoints in an
interview and in production. Full JPA/Hibernate internals are Book 7;
full OAuth2/JWT/DevSecOps depth is Books 5 and 15. Cross-references are
called out explicitly in each chapter so the progression stays coherent.
